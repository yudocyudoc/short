# Instrucciones compartidas C5

Construye el grafo mínimo de stocks y flujos de dinámica de sistemas para la biblioteca descrita. Aplica la prueba de la fotografía: un stock persiste si el tiempo se detiene, un flujo transporta entidades entre estados. Usa balances inicial + entradas − salidas = final, unidades consistentes y órdenes de eventos permitidos. Distingue hechos observados, acumulaciones, estados de frontera e información no identificada.

Evita inventar flujos de reserva como transferencias físicas o viceversa. No inventes bucles endógenos ni tasas instantáneas a partir de totales semanales. Devuelve solamente el JSON del contrato.

No se suministran los saldos finales resueltos.
